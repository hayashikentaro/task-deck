# Implementation Guides

`docs/guides/` contains responsibility-specific implementation guidance. `AGENTS.md` is the top-level router and should link to these guides instead of duplicating their details.

If a recurring rule applies only to a specific area, create or update a concise guide here and link it from `AGENTS.md` when relevant.

Current guides:

- `ui-style.md`: CSS, visual variants, and style ownership for `apps/web`.
- `ui-components.md`: reusable UI component and control implementation rules for `apps/web`.
